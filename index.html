    Operational definitions for a scoped baseline and pilot
    MetricDefinition / unitCollection method
    Brief → validated conceptMedian elapsed days; fixed validation criteriaBrief timestamp → review + user evidence
    Design production rateAccepted artifacts per team-weekSame artifact class, scope, and acceptance rubric
    Production / review effortPerson-hours per accepted concept; report separatelyTime log including critique + validation
    Rework / revision rate% reviewed artifacts requiring a major revisionRevision log; agree “major” before starting
    System compliance% applicable design-system checks passedToken, component, and interaction-pattern audit
    Accessibility / quality defectsOpen defects per 10 reviewed screens + severityManual and automated checks, deduplicated
    Design-to-code divergence% audited UI instances violating approved intentPaired design/code review of a defined sample
    Experimentation / reuseCompleted experiments/week; % work citing approved contextDecision log; context provenance in artifacts

    Match scope + staffing. Record sample size + spread. Audit sampling bias. Track customer task success separately.
    Small pilots are directional—not causal proof. Set adoption / revise / stop criteria before seeing results.
